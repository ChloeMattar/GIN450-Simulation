Every instruction starts with fetch & decode. CISC pays more there because its instructions vary in length and can expand into several internal steps; RISC uses one fixed format. All other costs are the same for both.

Counters come from the actions the simulator actually executes. Animation speed only changes how fast you watch; it never changes the cycle count.

This model runs one action at a time, with no pipelining, caches, or overlap. Real processors do all of these, so the cycle counts here show the trade-off, not which design is faster.

Glossary
Instruction
One command in a program, such as ADD or LOAD. The processor fetches it, decodes it, and carries it out through one or more internal actions.
Register
A tiny, very fast storage slot inside the processor. These models each have four: R0 to R3.
Memory
Larger storage outside the processor that holds the program's data, here A, B, D, the list X, and the result RES. Reaching it takes longer than reaching a register.
ALU
Arithmetic logic unit: the circuit that actually adds, subtracts, and multiplies. It takes two inputs and produces one output.
LOAD
A RISC instruction that copies a value from memory into a register. In RISC, it is one of only two instructions allowed to touch memory.
STORE
A RISC instruction that copies a value from a register into memory. The other memory instruction.
Clock cycle
One tick of the processor's clock, the basic unit of time. Each internal action costs some number of cycles; this simulation uses the costs in the timing assumptions.

About this model

Both instruction sets are simplified teaching inventions. The assembly is educational pseudocode, not real x86 or ARM code.

CISC (complex instruction set computer) lets a single instruction read memory, compute, and write memory. RISC (reduced instruction set computer) keeps instructions simple: only LOAD and STORE use memory, and arithmetic works on registers.

Neither approach is always faster. Real results depend on the program, the instruction set, the compiler, and how the processor is built. Many modern CISC chips translate instructions into simpler internal operations, and many RISC chips overlap instructions heavily. Not every RISC instruction takes one cycle, and CISC does not always use fewer instructions.
